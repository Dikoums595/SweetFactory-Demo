# Sources techniques SweetFactory

Ce dossier accueille les fichiers de travail qui ne sont pas directement des pages du site de documentation.

## Organisation proposée

- `process/` : synoptiques, schémas de flux et description du procédé.
- `automation/` : exemples pédagogiques de séquences, variables et scénarios de test.
- `models/` : modèles 3D et exports de maquette, si le projet en utilise.

## Règles de contribution

- Utiliser des noms de fichiers courts, explicites, sans espaces ni accents.
- Indiquer la date et la version des exports importants.
- Ne pas déposer de fichiers confidentiels ou de données personnelles.
- Documenter le logiciel utilisé et les limites connues de chaque fichier.

Les images optimisées destinées au site sont rangées dans `docs/assets/images/`.
